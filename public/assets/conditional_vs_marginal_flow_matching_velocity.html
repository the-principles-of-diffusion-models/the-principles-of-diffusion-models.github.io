Interactive · Conditional vs Marginal Velocity Fields

Flow matching trains a network to predict a velocity field transporting noise x₁ to data x₀. In the conditional view, x₀ is known, so there is one clean target direction. In the marginal view, the network only sees (xₜ,t): the same point can have several plausible target velocities. The colored arrows now show those competing conditional directions; the red arrow is the averaged marginal target.

flow time t = 0.40 (0 = noise source, 1 = data)
